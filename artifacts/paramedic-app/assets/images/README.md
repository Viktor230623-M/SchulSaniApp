# Instanzspezifische Bilder

`icon.png` (App-Icon) und `splash-icon.png` (Startbildschirm) zeigen das Logo
des Sanitaetsdienstes der aktuellen Instanz. Bei einer neuen Installation
diese beiden Dateien unter denselben Namen und Massen durch das Logo der
neuen Schule ersetzen — Code oder Konfiguration muss dafuer nicht geaendert
werden.
